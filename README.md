# Financiación Movilidad

Primera maqueta estática y responsive para Study Abroad/OIA.

- 8 tarjetas ficticias.
- Filtros combinables: tipo de estudiante, nivel académico, facultad y tipo de movilidad.
- Botón limpiar y contador de resultados.
- Sin dependencias ni backend: compatible con GitHub Pages.

## Edición

Los registros de muestra están en el arreglo `supports` de `script.js` y las opciones de filtrado en `filters` del mismo archivo. **No son datos oficiales.**

## Publicación

Sube los archivos a la rama `main` del repositorio y ve a Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
